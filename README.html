Prévia de telas para validação

Telas estáticas (HTML) para validar o produto antes do desenvolvimento. Os dados são fictícios. Clique nos cards abaixo para navegar pelo fluxo — não há backend, então botões como "Enviar e-mail" são apenas visuais.

v2 — ajustes a partir da análise do sistema Duo Test (atual):
  • Marcação de Pseudópode (eleva grau para ++++) e Dermatografismo (invalida o item como XXXX).
  • Coassinatura médico + enfermeira (Nome + COREN) na personalização.
  • Conceito de "Modelo de laudo" (não "bateria") — agrupa substâncias + fornecedor + tipo de aplicador + texto padrão. Nova tela Meus modelos.
  • Fornecedor de extrato e Tipo de aplicador (Multi-Test PC / Duotip-Test II / Unitest PC) no PDF.
  • Botão Modificar após o laudo gerado.
  • Botões +/− ao lado do campo de mm para incremento rápido.
Escopo desta fase: apenas Prick Test. O card Patch Test aparece marcado como "Em breve" e será desenvolvido em uma próxima fase, sobre a mesma arquitetura.

Cabeçalho, rodapé e assinatura no laudo estão representados por placeholders pontilhados. Na versão real, são imagens JPG enviadas pelo médico.

O que evoluiu em relação ao Duo Test (sistema atual)
  • Catálogo de substâncias com campos descritivos (% concentração, veículo, onde é encontrada, reação cruzada, observações).
  • Página 2 automática do laudo com orientações só dos positivos.
  • UI anatômica de marcação no antebraço.
  • Envio do laudo por e-mail (médico + paciente).
  • Cabeçalho e rodapé independentes (não só "logo").
  • Histórico com filtros por modelo, período e status; busca por nome.
  • Auditoria/LGPD: registro de emissão, envio e abertura.
  • Arquitetura preparada para apps iOS/Android e novos tipos de teste (Patch em breve).
